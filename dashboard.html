02 · 보류 중인 아이디어

AI 에이전트 동료

2026-08-23에 처음 나온 컨셉 — 아직 착수 전, 어느 로드맵에도 우선순위로 안 잡혀 있지만 버리기엔 아까워서 여기 남겨둔다.

컨셉

채팅창에 자연어로 동료에게 지시를 내리면("여기서 좀 쉬고 있어", "저 나무 좀 캐줘"), LLM Function Calling으로 그 지시를 실제 게임 행동(이동/채집/대기 등)과 대사로 실시간 변환해 동료가 그대로 움직인다는 아이디어. 지금의 규칙 기반 팔로우 AI(거리 기반 추종, 정해진 대사 풀)보다 훨씬 유연한 동료 상호작용이 가능해진다.

왜 아직 안 하나

비용(매 지시마다 LLM 호출)·지연(실시간성 요구되는 게임 루프와 API 응답 시간의 충돌)· Steam AI 기능 고지 의무 같은 리스크가 있어 신중한 검토가 필요 — GDD 4장(게임플레이)과 17장(리스크)에 이미 상세가 적혀 있다. 지금 로드맵(1~4막)에는 포함돼 있지 않고, 베이스 게임을 다 낸 뒤에나 재검토할 후보.

이 문서는 2026-08-23 작성된 "통합 대시보드"를 2026-08-29에 정리한 것 — 원래 있던 진행현황· 캐릭터·에셋·이슈&라이선스·문서허브 5개 탭은 로드맵· 1막 문서·ASSETS.md·문서 허브에 이미 더 정확하게 있어 삭제했다. 최신 상태는 항상 그 원본 문서들이 기준.
